# Blog

把和 AI 的讨论，整理成可回看的想法笔记。

一篇只讲一个想法，500–1000 字；重点不是 AI 说了什么，而是**我采纳了什么、没采纳什么、为什么**。

## 系列

- **AI 产品**：能力边界、系统设计、评测与验证
- **数据与风控**：Text2SQL、指标体系、预测与预警
- **和 AI 协作的方式**：从对话时代到 Agent 时代的使用心得

## 写作约定

- 新文章复制 [`_template.md`](./_template.md) 到 `posts/`，文件名用 `YYYY-MM-DD-简短主题.md`
- 只保留结论和自己的判断，不整段粘贴对话原文
- 不涉及公司内部数据、未发表的研究细节和他人隐私
- `status: draft` 的文章不加入上面的文章列表，整理完改为 `published`
